** [[https://zen-browser.app/][Zen Browser]]
   @@html:<video controls src="https://zen-browser.app/media/hero-video/video.webm"

   Firefox-based browser with unique features such as:
   - Multiple workspaces
   - Essentials
   - Glance

   Can't say much about it, it's just a very convenient ⭐beautiful⭐ minimalist browser, I recommend it to everyone.
** [[https://github.com/YaLTeR/niri][niri]]
   @@html:
   <video controls src="https://github.com/YaLTeR/niri/assets/1794388/bce834b0-f205-434e-a027-b373495f9729">
   </video>@@

   This is a Wayland window manager (WM) with scrolling-tiling, written in Rust using [[https://github.com/Smithay/smithay][smithay]].
   (look for the rest of the information in the repository)

   I wasn't familiar with scrolling-tiling before, but I quickly got used to it and find it the most convenient way to interact with tiled windows.

   Very fast developing, in just a few months of my use, very useful features have appeared, such as:
   - [[https://github.com/YaLTeR/niri/wiki/Overview][Overview]]
   - [[https://github.com/YaLTeR/niri/wiki/Configuration:-Recent-Windows][Recent windows (Alt-Tab)]]
   - [[https://github.com/AvengeMedia/DankMaterialShell/][DankMaterialShell]]  \\
     This shell combines several tools, so now I don't have to install separate tools (waybar, swww, gtklock, etc.), but can use just one.

*** [[https://github.com/nvim-orgmode/orgmode/][neovim-orgmode]]
    [[https://user-images.githubusercontent.com/1782860/123549968-8521f600-d76b-11eb-9a93-02bad08b37ce.gif]]

    You can check out the showcase here: [[https://github.com/nvim-orgmode/orgmode/tree/9fdc30e05378691e8c51a22113fc22e30cdc14cc?tab=readme-ov-file#showcase][neovim-orgmode showcase]]

    Actually, orgmode is an Emacs thing. A very high-quality clone was written for neovim (though I can't say how close it is to the original).
    Before this, I used various tools for taking notes, calendar, and todo lists. This tool combined all of them.
    To be honest, sometimes I can't stick strictly to the planned day, but I think it's because of my mindset and I need to get used to the tool.

    I also use Syncthing and Orgzly for planning on my phone.  \\
